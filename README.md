# 課題1 進捗管理ボード

タスクの登録・状態管理・削除ができる、シンプルな進捗管理ボードです。
HTML / CSS / バニラ JavaScript のみで実装しています（フレームワーク・ビルド不要）。

## 機能

- **タスクの追加**: タスク名（必須）・期限・ステータスを入力して一覧に追加
- **ステータス変更**: 一覧の各タスクで「未対応 / 処理中 / 完了」を切り替え
- **タスクの削除**: ゴミ箱アイコンから対象タスクを削除

## 使い方

ビルドやサーバーは不要です。`index.html` をブラウザで直接開くだけで動作します。

```bash
open index.html
```

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面のマークアップ（追加フォーム・タスク一覧） |
| `app.css` | スタイル。`:root` にデザイントークン（色・余白・角丸など）を定義 |
| `app.js` | タスクの追加・削除・ステータス変更のロジック |
| `trash.svg` | 削除ボタンのアイコン |

## 実装メモ

- タスクは `tasks` 配列でメモリ上に保持します（リロードすると消えます）。
- 各タスクは `taskId`（連番）で一意に識別しています。
- 一覧のクリック／変更はリスト要素へのイベント委譲で処理しています。
